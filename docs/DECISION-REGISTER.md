## ترتيب الحسم

1. قبل أساس محلي: تكليف برمجي مستقل؛ TEC-* أساسه. لا ضرورة لحسم الغذاء أو host أولًا.
2. قبل تثبيت التسجيل: A-02 والجوانب الأمنية من A-08 و A-12. البريد المحلي يتيح تأجيل اختيار الإنتاج A-09.
3. قبل القوالب والسياسات: A-01/A-05 ثم A-03 ثم A-04. A-10 قبل توزيع الأصول.
4. قبل المدرب والتصحيح الإداري: A-11 مع A-02/A-07/A-03 وتمثيل منح RV-01.
5. قبل موارد الإنتاج: A-06 ثم A-07/A-08/A-09 ، بما فيها هوية المرسل و DNS والنسخ المستقلة.
6. قبل النشر: إغلاق البوابات واجتياز الاختبارات ثم موافقة نشر صريحة؛ دمج main موافقة مستقلة.

## إغلاق القرار وأثره

لكل قرار: ID ، السؤال، الخيار المختار، البدائل وسبب رفضها، صاحب الصلاحية ودليل موافقته/تأهيله، التاريخ، نطاق ونسخة القرار، أثره على R/T/RV ، ومراجعة قانونية/صحية حيث تلزم. لا يغلق Codex قرار المالك أوالمختص نيابة عنه. تغيّر القيم يسجل بإصدار جديد ولا يمحو القرار القديم أو يعيد حساب الماضي دون مراجعة أثر صريحة.

الحالة الحالية: جميع A-01..A-12 مفتوحة كليًا أو جزئيًا؛ TEC-01..08 معتمدة كنهج تقني فقط، غير منفذة. سجل تغيير 1.0: تصنيف القرارات، بوابات المراحل، نهج البداية المحلي، وخيارات الخدمات مع قيودها.

## ملحق تنفيذ P2 — 2026-10-11

بموجب تكليف المالك P2، حُسما RV-01 وRV-02 تقنيًا ونفذا محليًا: grants بموافقة ونطاق/انتهاء/سحب، وعلاقات مركبة ومصادر/تعارض/سحب ونسخ. التفاصيل والأسباب في [P2-DATABASE-IMPLEMENTATION](P2-DATABASE-IMPLEMENTATION.md)، والأدلة في [P2-TEST-RESULTS](P2-TEST-RESULTS.md). لا يغلق ذلك A-01..A-12 أو بقية RV ولا يجيز P3 أو حسابات حقيقية أو نشرًا. أي عبارة سابقة «غير منفذ» تصف مرحلة الوثيقة التاريخية.

## ملحق P4 — نطاق التسوية التقنية

تكليف المالك يبدأ من P3 المعتمد، وينفذ محليًا فقط. RV-10 سوي للبرامج والإصدارات والمحتوى وفق جدول [P4-PROGRAM-ENGINE](P4-PROGRAM-ENGINE.md)؛ حالات المشاركة وقفل الأيام تبقى لـP5. RV-07 مطبق ضمن أوامر P4: If-Match وإيصالات Idempotency-Key وأقفال الآباء، دون تعديل سياسات المالك. المدد والحدود والأهداف والإدارة والتأهيل أمثلة اصطناعية محلية؛ لا تغلق A-01 أو A-05 أو A-10 أو A-12 أو أي قرار آخر. نشر المصادر الحقيقية والتحويلات غير المعتمدة وbootstrap الإنتاجي محجوب.
