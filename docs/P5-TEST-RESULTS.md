التكامل يختبر 7/15/21 يومًا، snapshots والتكرار والمواعيد النسبية، منع الانضمام المكرر وإعادة الطلب، البداية الثابتة والمستقبل، إتمام/تراجع/تزامن، المستخدمين A/B، RLS وقيود تعديل snapshot وقفل اليوم، تغيير timezone، الانسحاب والحفظ التاريخي ومنع الانضمام للبرنامج المتوقف. قيد مؤجل يرفض المشاركة الناقصة، ولا يمكن تعديل حقول occurrence الثابتة.

الإخفاقات المصححة: تعريف SQL helper تحت FORCE RLS قبل نقل ملكيته؛ استُخدم PL/pgSQL ودور سياسة محدود. FOR SHARE من حساب المشارك أخفى نسخة الانضمام بسبب UPDATE policy؛ helper ضيق يقفل النسخة دون توسيع تحديث البرامج. أعيدت صلاحيات INSERT/UPDATE التي حجبها P2 إلى خدمات المشاركة فقط تحت RLS. Lint كشف رابط a داخلي وأصلح إلى Link. E2E كشف محددات عامة التقطت تنبيهات التحميل/Next؛ حُددت رسالة التطبيق، وأثبت غياب نجاح زائف بفشل الحفظ503.

لا تعني هذه النقطة نجاح P6/P7 التشغيلية أو انحدار PostgreSQL/E2E النهائي؛ يعاد تشغيلها ضمن التقرير المشترك. لا قبول سياسة A-03 أو اختبار قارئ شاشة يدوي أو جهازين مستقلين أو إنتاج. أي فشل سابق موثق لا يسجل نجاحًا قبل إعادة التشغيل.

## مراجعة التكامل اللاحقة

نجحت إعادة native P5 في 12 مجموعة، بما فيها إتاحة أحدث نسخة منشورة مع ثبات المشاركة السابقة، وقراءة تاريخ المشاركة المنسحبة مع منع التعديل وفصل الملكية. أضيف اختبار متصفح لفقد رد إتمام محفوظ ثم إعادة نفس الجسم والمفتاح والتحقق من سجل واحد؛ تشغيله النهائي معلق حتى التقرير المشترك. فحص check الكامل بعد تصحيحات المهمة القادمة نجح: TypeScript وLint و58 اختبار وحدة وBuild. نتائج نقطة P5 الأصلية أعلاه تاريخية ولا تستخدم بدل إعادة الاختبار.

النتيجة النهائية: 12 مجموعة native و9/9 E2E ناجحة بعد التصحيحات؛ ضمن99/99 E2E نهائية. TypeScript وLint وBuild و58/58 وحدة ناجحة. سجل الانحدار والأعطال والأسرار ونقاط Git في [التكامل](P5-P7-INTEGRATION-REPORT.md). الفقرات التي تسمي إعادة معلقة أعلاه توثق مراحل التشغيل السابقة؛ هذه النتيجة هي الأحدث.
