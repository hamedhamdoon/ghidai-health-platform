التكامل يثبت C/N الاختيارية، فصل المستحق وكامل المدة، null وصفر وغياب، إتمام كمي من الماء والخطوات والرياضة والنوم ثم حذف الماء وإلغاء الشارات، تراجع/إعادة استحقاق بrevision حالي، شهادة اختبار من مصدر تاريخي متكامل بعد المدة، رفض تنزيل قديم بعد التصحيح وسحب award/certificate، مصادر مسحوبة، RLS لمستخدمين مستقلين وADMIN/COACH غير مخولين، ورفض تعديل SQL مزور للإثبات أو الشهادة وسلطة backdate من app. fixture تاريخي لا يغير نسخة أو مشاركة موجودة ولا يجيز محتوى صحيًا مرجعيًا.

المتصفح يطبق فلاتر تاريخ ومشاركة على استجابة الخادم الفعلية، يتحقق من اسم النسخة، ينزل JSON ويفحص محتواه الخاص الاصطناعي، ثم يتراجع عن المصدر ويثبت فشل التنزيل وسحب الاستحقاق. رسائل انقطاع/غير مخول تظهر بلا جدول أو بيانات مخترعة.

الإخفاقات المصححة لا تخفى: تشغيل أول3/6 فشل بسبب اسم select المتاح الذي احتوى عناوين الخيارات؛ أضيف اسم عربي صريح. تشغيل تال3/6 فشل بشرط axe scrollable-region-focusable؛ أضيف region وtabIndex واسم عربي، وأعيد الاختبار دون تخفيف شرط صفر مخالفات. التشغيل النهائي6/6 أثبت التنزيل والفلاتر والإتاحة. أدلة اللقطات والأخطاء محفوظة محليًا في .npm-cache.

حدود الاختبار: ثلاث عروض متصفح محلية لا جهازان مستقلان؛ لا قارئ شاشة يدوي أو حمل إنتاج أو توقيع شهادة أو HTTPS عام. لا قبول A-03/A-04 أو ادعاء انجاز صحي حقيقي. نتائج الانحدار والتكامل والأعطال النهائية في التقرير المشترك.

النتيجة النهائية: 12 مجموعة native و6/6 E2E ناجحة بعد014؛ ضمن99/99 E2E نهائية. TypeScript وLint وBuild و58/58 وحدة ناجحة. سجل الانحدار والأعطال والأسرار ونقاط Git في [التكامل](P5-P7-INTEGRATION-REPORT.md). الفقرات التي تسمي إعادة معلقة أعلاه توثق مراحل التشغيل السابقة؛ هذه النتيجة هي الأحدث.
