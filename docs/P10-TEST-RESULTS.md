## القياسات المنفذة

Chromium156.0.8078.4 على Windows، production build نهائي محلي، دون جلسة، context جديد وHTTP cache معطل لكل عينة. ليست بيانات مستخدمين أو حملًا متعدد المستخدمين. ملف النتائج النهائي `.npm-cache/p10-performance.json` خارج مجلد Playwright الذي ينظف أثناء E2E. الجولة الأولية كانت محفوظة في test-results وحذفها تنظيف P8 المعتاد؛ أعيد القياس النهائي إلى المسار الدائم المحلي.

CLS بين 0.0000615 و0.0135123؛ DOMContentLoaded بين 407.1 و4813.9ms؛ JSHeapUsedSize عبر CDP بين 2566964 و2710448bytes. لا overflow في12/12. encodedBodySize يقيس جسم الاستجابة المشفر وفق نقل المتصفح، وليس ادعاء قياس gzip مستقل. عند تفسير ميزانية150KB بالعشري فإن `/today` يتجاوزها بمقدار1226bytes؛ القيم كلها أقل من150KiB. لا يعلن نجاح ميزانية gzip مستقلة من هذا القياس، ولا تثبت هذه العينات كل الشاشات أو حالات المستخدم المصادق.

التشغيل الأول أخفق داخل أداة القياس بسبب تسلسل function في addInitScript مع tsx؛ صحح بجسم قياس عادي وأعيد التنفيذ كاملًا exit0. الجولة الأولية تزامنت مع أعمال فريق P8، فلا تعد قياسًا معزولًا. الجولة النهائية حجزت المنفذ3100 تسلسليًا بعد build النهائي. قبل تصحيح انتظار load الكامل سجلت عينتان LCP=2532/2748ms (تجاوز2.5s) وسجلت عينتا ترحيب DOMContentLoaded=0 غير مكتمل؛ حفظت القيم في `.npm-cache/p10-performance-before-load-wait.json`. أضيف انتظار load وأعيدت12 عينة كاملة دون تغيير التطبيق؛ الجدول أعلاه آخر جولة، ولا تخفى تجاوزات الجولة السابقة أو تباينها. عينات منفردة لا تمثل p95 أوSLA أوINP؛ لا Lighthouse أو workload PostgreSQL بهذا التقرير.

الإتاحة تشمل skip link/focus، CSS zoom 200%، reduced-motion وaxe عند تشغيلE2E. لم يجر اختبار NVDA/VoiceOver عربي عملي أو native browser zoom أو جهازين مستقلين. تشغيل cache/offline يقيس Chromium المحلي، ولا يثبت تثبيت/سلوك جميع الأجهزة أو background delivery.

## دليل PWA والخروج الفعلي

Chromium `Page.getAppManifest` أعاد errors=[] وموقع manifest صحيحًا في العروض الثلاثة. احتوى CacheStorage الأيقونتين وoffline.html فقط بعد طلبات health/CSRF. عند الانقطاع فشل API اليوم، وانتقال `/progress` أظهر صفحة عامة دون السجلات. ليست شهادة تثبيت نظام تشغيل؛ قبول التثبيت على الأجهزة المتوافقة يظل اختبارًا عمليًا غير منفذ.

استخدمت fixture مشاركًا اصطناعيًا وجلسة حقيقية: الحساب محمل أولًا، ثم انقطاع فعلي، ثم ضغط «تسجيل الخروج» أظهر خطأ عربيًا وبقي cache ومؤشر Session.revokedAt=null. بعد الاتصال نجح الزر نفسه وانتقل إلى login، وحذف cache وأثبت revokedAt بالقاعدة. لم يرسل حدث خروج يدوي لإثبات النجاح.

الجولة الأولى 33/36: تعارض selector alert مع Next route announcer؛ قيد بـ.pwa-status. محاولات mock لإخفاق الخروج كانت غير حتمية؛ استبدلت بانقطاع فعلي. بدء أول انقطاع قبل تحميل الحساب منع زر الخروج، فأضيف networkidle وتحقق ظهور الزر؛ نجحت focused 3/3 ثم full 36/36. لم تخفف عتبة axe أو العزل. أعلنت جهة التكامل بدء check أثناء آخر جولة؛ لم تظهر أخطاء .next، ويعاد قبول النسخة النهائية بعد اكتمال بنائها في تقرير التكامل.

إعادة التشغيل: `npm run build` ثم `npx playwright test p10-pwa.spec.ts`؛ النتائج النهائية والأعطال والانحدار والأداء في تقرير التكامل مع بيان أي فحص تعذر تشغيله.
