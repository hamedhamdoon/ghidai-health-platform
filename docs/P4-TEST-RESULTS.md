## ما اختبر فعليًا

إنشاء وتعديل مسودة ومدة7/15/21، التكرار والتوسيع وتغيير المدة، جميع أنماط الموعد وكشف الدورات في DTO وSQL deferred trigger، نقص الأيام، ثبات المنشور والنسخ المستقل، تعارض التعديلات بفائز واحد، receipt/replay مختلف المدخل، منع USER وCOACH غير المالك، انتهاء capability، استقلال المراجع والنطاق والتأهيل المنتهي والرفض/hash المزور، دليل تأهيل ثابت، منع نقل المؤلف أو تصنيف مصدر حقيقي إلى اصطناعي، MFA الحالي والمسار البديل، سحب وأرشفة نهائيان.

الغذاء: كميات عشرية ومكونات وبدائل، قيمة سلبية ووحدة مجهولة ومعامل غير معتمد، بديل ذاتي، graph مجمد أثناء المراجعة، نشر خطة ووجبة وبديل اصطناعيين بعد الاعتماد، وسحب البديل يحجب العرض. الواجهة تحفظ مكونين وبديلًا فعليًا، وتجربة فقد استجابة بعد commit ثم إعادة الطلب تبقي ContentRevision واحدة. فحص P4 يؤكد عدم إنشاء Enrollment أوTaskOccurrence.

اختبارات المتصفح تتضمن العربية وRTL وعدم overflow، ترتيب المهام بلوحة المفاتيح، وaxe على وسوم WCAG2.2AA دون مخالفات في شاشة النشر. الصور المحلية محفوظة أيضًا في .npm-cache/p4-admin-{360,768,1280}px.png حتى لا تمحوها جولة Playwright لاحقة؛ فحص بصري فعلي للعرض360.

## الإخفاقات المصححة

1. sandbox منع SWC canonicalize وPostgreSQL وDocker pipe؛ أعيد التنفيذ بصلاحية محلية ولم تعتبر المحاولات الأولى ناجحة.
2. إنشاء دالة SQL أثناء migration004 اصطدم بـFORCE RLS. صححت الدوال وملكية التنفيذ؛ تحقق rollback بغياب الجدول والعمود قبل resolve rolled-back. لا حذف أو تعديل P2/P3.
3. اسم نطاق idempotency احتوى رقمًا يرفضه عقد P2؛ صحح إلى programs.command دون تغيير العقد. قفل التأهيل نقل إلى دالة سياسة محدودة مع clock_timestamp.
4. أول E2E0/6: label احتوى خيارات select ففشل التحديد الدقيق، وalert طابق announcer الخاص بـNext. أصلح htmlFor/useId وحدد التنبيه داخل main؛ الجولة التالية6/6.
5. جولة التغطية الموسعة10/12: تكررت عناوين fixtures بين المشاريع الثلاثة فأصبح locator غير مميز. أضيفت لاحقة فريدة للبيانات؛ معايير حفظ المكونات والبديل لم تتغير. الجولتان التاليتان12/12.
6. Lint رفض Date.now أثناء render؛ احتساب أهلية التأهيل انتقل إلى الخادم دون إسكات القاعدة. آخر check ناجح.
7. ملفات audit المكتوبة داخل test-results أزيلت أثناء تهيئة Playwright؛ أعيد الفحص وحفظت التقارير في .npm-cache. لم يعتبر غيابها نتيجة صفر.

8. مراجعة Git رصدت CRLF في migration004 بينما .gitattributes يثبت SQL على LF. تحقق hash النسختين وأن الاختلاف نهايات أسطر فقط، ثم وحّد الملف وسوّى صف ledger004 وحده في قاعدتي GHIDAI المحليتين بسكربت محصور في hash محددين ومع Audit. لم تتغير عبارات SQL أو P2/P3، وأعيدت probes/checksums بعد التسوية.

## حدود الأدلة

لا يثبت axe أو keyboard قارئ شاشة عربيًا يدويًا. Lighthouse/حمل إنتاج/جهازان مستقلان/قبول قانوني/استعادة إنتاج غير منفذة. الاختبار المحلي لا يغلق قرارات المالك أو يؤهل شخصًا حقيقيًا. tmpfs كانت متوقفة عند البداية وسجل المهاجرات غائبًا بعد تشغيل الحاوية الموجودة؛ المخططات المولدة في هذه الجولة محفوظة أثناء استمرار Docker، ولا يدعى بقاء بيانات tmpfs عبر الإيقاف.
