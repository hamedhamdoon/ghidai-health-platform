# P10 — PWA وتجربة الاستخدام والإتاحة

2026-10-14 Asia/Muscat. تنفيذ محلي ضمن تكليف P8–P10؛ لا P11/P12 أو نشر عام. A-01..A-12 تبقى مفتوحة.

## التنفيذ

- `src/app/manifest.ts`: manifest عربي RTL، standalone، أيقونات PNG 192/512 وmaskable، بداية `/today`.
- `public/icons`: رسم هندسي أصلي أنشئ لهذا المشروع، بلا أصول خارجية أو صور مرجعية. قابلة لاستخدام المشروع؛ لا يغلق ذلك A-10 الخاص بأصول المالك.
- `public/sw.js`: allowlist ثابت فقط لأيقونتين وصفحة انقطاع عامة. لا تخزين HTML التطبيق أو RSC أو API أو جلسات أو بيانات صحية أو Next chunks. الطلبات غير المدرجة تبقى طلبات شبكة؛ الكتابة لا تعترض ولا تصطف دون اتصال. صفحة الانقطاع لا تحتوي بيانات مستخدم.
- `src/components/pwa-status.tsx`: تسجيل worker في secure context (يشمل loopback)، حالة اتصال عربية، زر تثبيت بعد `beforeinstallprompt` فقط، حدث خروج لتنظيف مساحة GHIDAI العامة. إزالة cache لا تمس مساحة تطبيق آخر. لا ادعاء تسليم Push بعد إغلاق المتصفح.
- `next.config.ts`: worker يعاد فحصه دون HTTP cache. styles: focus لجميع العناصر، حركة مخفضة، قيود عرض الحقول وtouch targets. خمس وجهات أصلية محفوظة، والقائمة لا تتسع بوظائف الإدارة الجديدة.
- صفحة المساعدة تشرح الوظائف الموجودة وحدود التثبيت/الانقطاع، وإزالة عبارة قديمة تدعي عدم تنفيذ البرامج والسجلات.

## التحقق وإعادة التشغيل

`npx vitest run tests/unit/p10-worker.test.ts` و`npx playwright test p10-pwa.spec.ts` بعد build. اختبارات المتصفح تدقق cache الفعلي ورفض API offline وpurge، وتتأكد من keyboard/RTL/zoom/reduced motion وaxe عبر 360/768/1280. قياسات timing ونقل JS تحفظ مرفقات Playwright ولا تمثل هاتفًا فعليًا أو SLA.

تفاصيل التنفيذ الفعلية والحدود في [P10-TEST-RESULTS](P10-TEST-RESULTS.md)، والنتائج الشاملة في [تقرير التكامل](P8-P10-INTEGRATION-REPORT.md).

## الحدود المتبقية

لا offline health queue أو مزامنة محلية؛ لا cache بيانات صحة، لا اختبار تثبيت على جهازين مستقلين أو قبول قارئ شاشة عربي عملي. اختبار CSS zoom 200% يحاكي reflow بعرض لا يقل عن320CSSpx، ولا يثبت native browser zoom على جهاز مستخدم. فحوص axe لا تثبت اكتمال WCAG. نفذت12عينة قياس محلية للتحميل وLCP/CLS ونقلJS وJSheap؛ تفاصيلها وحدودها في تقرير الاختبار. لا قياس حملPostgreSQL أوp95/INP أوLighthouse شامل بهذا التسليم. النشر وقرارات سياسات الإنتاج ليست جزءًا من P10.
