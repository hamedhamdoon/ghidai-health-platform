## مصدر البيانات والتزامن

1. الانضمام يقفل النسخة المسموحة، ويحفظ version/policy/timezone/targets والترتيب، ثم يولد المجموعة الكاملة للأيام وoccurrences ذريًا. السجلات الموجودة قبل الانضمام تطابق مع المهام الكمية في المعاملة نفسها.
2. السجل الشخصي مستقل وله زمن حدث UTC ومنطقة محفوظة. كل مشاركة تطابق الحدث بمنطقتها المثبتة؛ النوم حسب الاستيقاظ، والخطوات snapshot يستبدل الإجمالي. عند وجود snapshots متقاطعة يؤخذ أعلى إجمالي مناسب، ولا تجمع الإجماليات اليومية كزيادات.
3. تصحيح السجل أو حذفه يعيد الإتمام DERIVED من المصدر، ثم يزيد إصدار المشاركة ويعيد الاستحقاق. إتمام MANUAL لا يتجاوز المهام الكمية، والاختيارية خارج N، وN=0 ينتج null.
4. القفل يبدأ بالـactor ثم المشاركة. If-Match يمنع الكاتب القديم؛ إيصال Idempotency-Key مرتبط بالمستخدم والعملية وpayload وإصداره، ويعيد نتيجة الطلب الملتزم بعد فقد الاستجابة دون كتابة ثانية.
5. الشارة والإثبات يطابقان aggregateRevision الحالي. سحب الشارة والشهادة ذري. عرض الشهادة وتنزيلها يعيدان فحص المصدر الحالي؛ خطأ السحب يصدر بعد commit حتى لا يلغي rollback تصحيح الحالة.

الرسم وجدوله البديل يقرآن القيم المحفوظة. نقطة صفر للخطوات تختلف عن فجوة الغياب. تقييمات مخططات مختلفة تحتفظ بمعرفاتها ولا تدخل متوسطًا موحدًا. الملف المنزّل للشهادة snapshot يحمل وقت التحقق وإصدار المصدر؛ الصلاحية الحالية تثبت من API خاص بصاحب الجلسة.

## ما يتطلب اعتمادًا قبل العمل اللاحق

الوظائف محجوبة عن الاستخدام الحقيقي بسياسات غير معتمدة. A-03/A-04 تخص النافذة والاستمرارية والعتبات والشهادة، وA-01/A-05/A-10/A-12 تخص المحتوى والأهداف والحقوق والتأهيل/الإدارة. A-02/A-06/A-07/A-08/A-09/A-11 تحتفظ ببوابات الجمهور والاستعمال والقانون والاحتفاظ والبريد والوصول. كل A-01..A-12 مفتوحة كليًا أو جزئيًا، ولا يغلقها اختبار أو هذا التقرير.

تخصيص أهداف برنامج بمعاملات صحية معتمدة، شهادات حقيقية، تصحيح إداري خارج النافذة، الوصول الإنتاجي للمدرب، نشر محتوى الصور، الاحتفاظ/التصدير والحذف الحقيقي، وإجراءات الإنتاج تحتاج قراراتها وتكليفها. P8 والتنبيهات وما بعدها لم تبدأ؛ التشغيل دون اتصال والمزامنة والنسخ المستقلة والنشر العام والدمج في main تحتاج نطاقًا واعتمادًا منفصلين.

ملاحظة انحدار P2: preflight الأول رفض AuditLog تشغيليًا محفوظًا من تصحيح P4 السابق. أتيح الاستثناء لاختبار P2 المعزول داخل ghidai_test ولـAuditLog فقط، مع إثبات بقاء عدد سجلاته دون تغيير. جميع فحوص P2 الأصلية42 شغلت ونجحت؛ أي جدول بيانات آخر غير فارغ لا يسمح به هذا الاستثناء. لم يحذف سجل أو مخطط أو Volume لتجاوز الفحص.
