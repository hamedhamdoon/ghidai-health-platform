الاختبارات تتناول CRUD ماء/كوب وإيصالات إعادة الطلب وتزامن التصحيح، مستخدمين مستقلين وADMIN/COACH غير مخولين، الخطوات استبدال/صفر/غياب/حذف/استعادة، عبور منتصف الليل وتداخل النوم، الرياضة والعادات والتراجع والأرشفة، خيارات التقييم وإصدارها ووزن اختياري وتاريخ مشفر للإجابات، إتمام كمية ثم إلغاؤه عند التصحيح/الحذف، وtimezone ثابتة وRLS مباشرة. المتصفح ينفذ الحفظ والتعديل والحذف والتقييم والاسترجاع، تسجيلًا سريعًا من اليوم، فشل503، وفقد الاستجابة بعد commit ثم إعادة طلب لا تضاعف السجل.

الإخفاقات المصححة: اسم سياسة audit مكرر من P5؛ اسم SQL مستعار day محجوز؛ تحويل PG date إلى UTC في DTO بدل التاريخ المحلي؛ إتمام كمي متأخر كان يستخدم وقت التسجيل الحالي بدل وقت المصدر؛ قيد حذف DERIVED عند سقوط الاستحقاق أتيح حتى بعد القفل مع إثبات المصدر. مراجعة بصرية360 كشفت أزرارًا قصيرة وأصلحت إلى48px ثم أعيد E2E. التشغيل المشترك كشف إغلاق runtime pools المشتركة بين ملفات Playwright؛ fixtures الآن تملك اتصالات مستقلة وتغلق مواردها وحدها.

مخططات الاختبار السابقة محفوظة. لا إنتاج أو بيانات فعلية أو اعتماد A-03/A-05/A-11. لا يدعى اختبار قارئ شاشة يدوي أو offline queue أو خدمة خلفية دائمة. تقارير الانحدار الكامل وP7 في التسليم المشترك.

يحفظ اختبار الاستجابة المتأخرة بيانات فعلية اصطناعية؛ يؤخر استجابة GET حقيقية، ولا يستبدل الحفظ أو القراءة ببيانات مصطنعة. يستخدم اختبار الكتابة المباشرة دور التطبيق وRLS ومعاملة تعاد إلى ROLLBACK بعد رفض القيد، ولا يحذف أي مخطط أو بيانات قديمة.

إعادة native النهائية بعد013:9/9 ناجحة، بما فيها رفض EXERCISE_NOT_FINISHED من الخدمة و23514 من PostgreSQL. التشغيل الأول لتأكيد SQL الجديد فشل42883 بسبب أسبقية AT TIME ZONE في نص الاختبار؛ صُحح تركيب SQL ثم أعيد دون تغيير شروط الرفض. فحص check الكامل بعد التصحيحات نجح: TypeScript وLint و58 وحدة وBuild. نتائج E2E النهائية ستضاف بعد اكتمال تشغيلها.

إعادة native بعد014:10/10 ناجحة. التشغيل الشامل السابق سجل23/24 للمشارك وإخفاق حفظ الماء768px مع شاشة خطأ React؛ الإعادة المحددة3/3 ثم الإعادة الشاملة96/96 نجحت قبل حسم السبب. وجدت المراجعة سببًا محددًا: options:null في نموذج DRAFT قيد إعداد موازٍ يسبب null.map. لم يُعتبر النجاح المتقطع إصلاحًا؛ أضيفت حماية الخدمة وRLS والواجهة ومعاملة fixture الذرية، ثم اختبار حتمي يبقي نموذجًا ناقصًا محفوظًا ويتحقق من الحجب وفشل النشر. اختبار المتصفح الإضافي لهذا السبب يعاد ضمن التشغيل النهائي (P6 الآن12 اختبارًا). دليل الفشل الأصلي محفوظ محليًا في .npm-cache/p6-final-retry-failure-768.png.
