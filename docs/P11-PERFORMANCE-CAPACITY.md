## Remaining acceptance and operational limits

Final LCP four-outlier acceptance remains OPEN; CLS/overflow/script-byte observations pass only within the measured matrix. Cloud quotas/cold starts/TLS overhead, production pooling, independent devices, authenticated browser vitals, INP/Lighthouse, long-duration or larger datasets and HTTP concurrent writes remain unproven. Free-provider usage/cost limits must be assessed using provider contracts and later authorized measurements, not extrapolated from loopback.

Monitoring's earlier storage alert and ephemeral-key BACKUP_NOT_VERIFIED remain operational concerns recorded separately; this document does not turn the short zero-error HTTP sample into a permanent error-rate feed or a successful usable production backup. No external service, scheduler or deployment was activated, and no existing schemas/volumes were deleted to improve results.
